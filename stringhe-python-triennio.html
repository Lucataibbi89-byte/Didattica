Le stringhe in Python

Creare, leggere, trasformare e formattare il testo, con esempi di biologia e chimica.

Prerequisiti: variabili, tipi int e float, funzione print(), ciclo for, liste e dizionari di base.

Obiettivi. Alla fine di questa lezione, lo studente:

  • crea stringhe con apici, virgolette e sequenze di escape;
  • legge caratteri e sottostringhe con indici e slicing;
  • spiega il concetto di immutabilità;
  • usa i metodi principali e le f-string;
  • scrive una funzione che elabora una sequenza di DNA.

Versione di riferimento: Python 3.8 o successiva. Tutti gli output sono stati generati eseguendo il codice.

indice positivo012345

Parte A — Le stringhe passo per passo

Fase 1 · Creare una stringa

  1. Una stringa è una sequenza di caratteri.

    Una stringa contiene lettere, cifre, spazi e simboli.

    In Python, il tipo di una stringa è str.

    Scrivete il testo tra apici singoli o tra virgolette doppie.

    codice
    nome = 'Ada'
saluto = "Ciao"
print(type(nome))
print(saluto, nome)
    output
    <class 'str'>
Ciao Ada
  2. Usate le virgolette triple per un testo su più righe.

    Le virgolette triple conservano gli "a capo".

    Usate questa forma anche per i commenti di documentazione (docstring).

    codice
    poesia = """Nel mezzo
del cammin"""
print(poesia)
    output
    Nel mezzo
del cammin
  3. Usate le sequenze di escape per i caratteri speciali.

    La barra rovesciata \ cambia il significato del carattere successivo.

    \n è un a capo. \t è una tabulazione.

    \' inserisce un apice nella stringa.

    codice
    print('L\'atomo\tdi carbonio')
print("Riga 1\nRiga 2")
print(len("\n"))
    output
    L'atomo	di carbonio
Riga 1
Riga 2
1

Fase 2 · Leggere i caratteri

  1. Ogni carattere ha un indice.

    Il primo carattere ha indice 0.

    L'ultimo carattere ha indice len(s) - 1.

    La funzione len() restituisce il numero di caratteri.

    codice
    s = "PYTHON"
print(len(s))
print(s[0])
print(s[5])
    output
    6
P
N
  2. Usate gli indici negativi per contare dalla fine.

    L'indice -1 indica l'ultimo carattere.

    L'indice -2 indica il penultimo carattere.

    codice
    s = "PYTHON"
print(s[-1])
print(s[-2])
    output
    N
O
  3. Non usate un indice fuori dall'intervallo.

    Un indice troppo grande causa un errore IndexError.

    Il programma si ferma.

    codice
    s = "PYTHON"
try:
    print(s[6])
except IndexError as e:
    print("IndexError:", e)
    output
    IndexError: string index out of range
  4. Usate lo slicing per estrarre una parte della stringa.

    La sintassi è s[inizio:fine:passo].

    Python include l'indice di inizio. Python esclude l'indice di fine.

    Se non scrivete un valore, Python usa il valore predefinito.

    codice
    s = "PYTHON"
print(s[0:2])
print(s[2:])
print(s[:3])
print(s[::2])
print(s[::-1])
    output
    PY
THON
PYT
PTO
NOHTYP

Fase 3 · Immutabilità

  1. Una stringa è immutabile.

    Non potete cambiare un carattere di una stringa esistente.

    Per un risultato diverso, create una nuova stringa.

    codice
    s = "gatto"
try:
    s[0] = "m"
except TypeError as e:
    print("TypeError:", e)
s = "m" + s[1:]
print(s)
    output
    TypeError: 'str' object does not support item assignment
matto

Fase 4 · Operatori

  1. Usate + per unire e * per ripetere.

    L'operatore + unisce due stringhe (concatenazione).

    L'operatore * ripete una stringa per un numero intero di volte.

    codice
    print("bio" + "logia")
print("ah" * 3)
print("-" * 20)
    output
    biologia
ahahah
--------------------
  2. Non unite una stringa e un numero.

    Python non converte i tipi in modo automatico.

    Usate str() per convertire il numero in stringa.

    codice
    eta = 16
try:
    print("Ho " + eta + " anni")
except TypeError as e:
    print("TypeError:", e)
print("Ho " + str(eta) + " anni")
    output
    TypeError: can only concatenate str (not "int") to str
Ho 16 anni
  3. Usate in per cercare una sottostringa.

    L'operatore in restituisce True o False.

    Il confronto distingue maiuscole e minuscole.

    codice
    dna = "ATGCGTA"
print("GCG" in dna)
print("gcg" in dna)
    output
    True
False

Fase 5 · Metodi

  1. Un metodo è una funzione della stringa.

    Scrivete il nome della variabile, un punto e il nome del metodo.

    Il metodo restituisce una nuova stringa. La stringa originale non cambia.

    codice
    s = "  Mitocondrio  "
print(s.upper())
print(s.lower())
print(s.strip())
print(repr(s))
    output
      MITOCONDRIO  
  mitocondrio  
Mitocondrio
'  Mitocondrio  '
  2. Usate i metodi per cercare e sostituire.

    find() restituisce l'indice della prima occorrenza, oppure -1.

    count() conta le occorrenze.

    replace() sostituisce una sottostringa con un'altra.

    codice
    dna = "ATGCGTATGA"
print(dna.find("TG"))
print(dna.find("CCC"))
print(dna.count("A"))
print(dna.replace("T", "U"))
    output
    1
-1
3
AUGCGUAUGA
  3. Usate split() e join() per le liste.

    split() divide una stringa e restituisce una lista.

    join() unisce gli elementi di una lista in una stringa.

    codice
    riga = "Na,K,Ca,Mg"
elementi = riga.split(",")
print(elementi)
print(" - ".join(elementi))
    output
    ['Na', 'K', 'Ca', 'Mg']
Na - K - Ca - Mg
  4. Usate i metodi di controllo.

    Questi metodi restituiscono True o False.

    codice

print("2026".isdigit())
print("H2O".isalpha())
    output
    True
True
False

Fase 6 · Formattazione e conversione

  1. Usate le f-string per inserire valori nel testo.

    Scrivete f prima delle virgolette.

    Scrivete le variabili tra parentesi graffe.

    Dopo i due punti, indicate il formato del numero.

    codice
    nome = "glucosio"
massa = 180.156
print(f"La massa molare del {nome} è {massa:.2f} g/mol")
print(f"{'C':>5}|{'H':^5}|{'O':<5}|")
    output
    La massa molare del glucosio è 180.16 g/mol
    C|  H  |O    |
  2. Convertite tra stringhe e numeri.

    input() restituisce sempre una stringa.

    Usate int() o float() per ottenere un numero.

    codice
    testo = "37.5"
t = float(testo)
print(t + 1)
print(int("42") * 2)
    output
    38.5
84
  3. Ogni carattere ha un codice numerico.

    ord() restituisce il codice Unicode di un carattere.

    chr() restituisce il carattere di un codice.

    Python confronta le stringhe con questi codici, carattere per carattere.

    codice
    print(ord("A"), ord("a"))
print(chr(67))
print("Zebra" < "ape")
    output
    65 97
C
True

Fase 7 · Scorrere una stringa

  1. Usate un ciclo for per leggere ogni carattere.

    Il ciclo legge i caratteri da sinistra a destra.

    Usate enumerate() per avere anche l'indice.

    codice
    for i, base in enumerate("ATG"):
    print(i, base)
    output
    0 A
1 T
2 G
  2. Esempio completo: il filamento complementare del DNA.

    Il programma legge ogni base e scrive la base complementare.

    Il programma costruisce una nuova stringa, perché la stringa originale è immutabile.

    codice
    def complementare(dna):
    coppie = {"A": "T", "T": "A", "C": "G", "G": "C"}
    risultato = ""
    for base in dna.upper():
        risultato += coppie[base]
    return risultato

print(complementare("atgcgt"))
    output
    TACGCA

NOTA: Nel passo 20, l'operatore += crea una nuova stringa a ogni ciclo. Per testi molto lunghi, il metodo "".join(lista) è più veloce.

Glossario

Regola ASD-STE100: un termine, un solo significato. Il testo usa solo questi termini per questi concetti.

TermineSignificato in questo testo
StringaSequenza ordinata e immutabile di caratteri (tipo str).
IndiceNumero intero che indica la posizione di un carattere.
SlicingEstrazione di una sottostringa con [inizio:fine:passo].
SottostringaParte continua di una stringa.
ImmutabileChe non cambia dopo la creazione.
MetodoFunzione collegata a un oggetto. Si scrive con il punto: s.upper().
ConcatenazioneUnione di due stringhe con +.
Sequenza di escapeBarra rovesciata seguita da un carattere con significato speciale.
f-stringStringa con prefisso f che inserisce valori tra parentesi graffe.

Nota sul linguaggio. ASD-STE100 è definito per la lingua inglese. Qui le sue regole principali sono adattate all'italiano: frasi brevi (procedure ≤ 20 parole, descrizioni ≤ 25), un'istruzione per frase, forma attiva, imperativo nelle istruzioni, avvertenze prima del passo, un termine per ogni concetto. Le parole chiave di Python e i nomi tecnici (slicing, f-string, escape) sono ammessi come technical names. Livello di conformità stimato: circa 80%.
